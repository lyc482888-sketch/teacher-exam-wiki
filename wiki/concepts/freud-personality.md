# 佛洛伊德：意識、人格結構與發展

## 核心概念

佛洛伊德（Sigmund Freud）的精神分析取向重視潛意識、早期經驗及心理衝突。本篇以教甄常見的結構與階段作歷史理論整理。

## 重點整理

| 人格結構 | 主要線索 |
| --- | --- |
| 本我 id | 立即滿足、快樂原則 |
| 自我 ego | 評估現實、協調需求與限制 |
| 超我 superego | 良心、理想與道德要求 |

- 意識、前意識、潛意識是意識層次；本我、自我、超我是人格結構，兩組不能直接一對一。
- 性心理階段：口腔期、肛門期、性器期、潛伏期、生殖期。
- 以本能衝突解釋行為，和 Erikson 強調社會文化與終身發展不同。

## 教學實例（AI 自編）

學生很想立刻拿走共同教具，同時想到輪流規則，再決定排隊等待；可用此情境練習辨認需求、現實協調與規範。

## 易混淆提醒

這是歷史理論，不用來推斷學生性傾向、診斷人格或宣稱幼年經驗決定一生。講義部分性別敘述不作為現代學生的能力判準。
