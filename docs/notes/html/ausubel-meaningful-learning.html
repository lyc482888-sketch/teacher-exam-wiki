奧蘇貝爾：有意義學習與前導組織

新知要和既有認知結構產生實質連結，接受講解也可以主動理解。

核心概念

奧蘇貝爾（David Ausubel）重視先備知識與有意義學習。教師可先提供更有概括性的架構，幫學生把新內容連到已有理解。

重點整理

  • 有意義學習：把新內容與已有概念建立可理解的連結。
  • 機械學習：缺少理解而記誦零散內容。
  • 接受學習：材料以完成形式呈現；不等於心理上被動。
  • 說明式前導組織：材料陌生時，先建立較概括的理解支架。
  • 比較式前導組織：已有相近知識時，釐清新舊異同。
  • 講解仍應搭配例子、提問、引導練習、獨立練習與回饋。

教學實例（AI 自編）

教臺灣地形前，先用地勢高低與起伏程度建立分類架構，再把各種地形納入比較。

易混淆提醒

前導組織不是任何笑話或活動；它要在認知上連結新舊知識。發現／接受和有意義／機械是不同分析面向。
