# 班杜拉的觀察學習

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/observational-learning.md`
- 摘要：觀察他人也能學習；學會與表現出來要分開看。
- 更新日期：2026-11-16

## 核心概念

班杜拉（Albert Bandura）指出，個體可透過觀察楷模學習，不一定要親身經驗每個行為後果。個人、行為與環境也會交互影響。

## 重點整理

| 歷程 | 關鍵問題 | 教學可做什麼 |
| --- | --- | --- |
| 注意 | 有看到重要步驟嗎？ | 清楚示範、凸顯關鍵 |
| 保持 | 能把步驟留在記憶中嗎？ | 說明步驟、整理口訣 |
| 再生 | 能實際做出來嗎？ | 提供練習、調整動作 |
| 動機 | 願意在此時表現嗎？ | 說明意義、給適當回饋 |

- **替代經驗**：由觀察他人的行為及結果獲得訊息。
- 不能僅因學生沒做出來，就判定他完全沒有學到。

## 教學實例（AI 自編）

美勞課教師示範安全使用剪刀，學生先觀察，再用自己的話說出步驟，接著實際操作。若學生能說清楚卻做不順，可以再檢查再生所需的練習，而不是只重複口頭說明。

## 易混淆提醒

四個歷程是分析學習條件的工具。看過一次不等於已會操作；會操作也不代表任何情境都願意表現。不要把所有同儕互動都直接歸為觀察學習。

## 自我檢核（AI 自編）

學生能說出教師示範的步驟，卻因操作技巧不足而做不出來，最需要加強哪個歷程？

- A. 注意
- B. 保持
- C. 再生
- D. 替代懲罰

**答案：C。** 已能說出步驟，表示已有部分保持；此例的困難在於將記憶轉為實際行動。
