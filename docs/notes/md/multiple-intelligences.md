# Gardner 多元智能：八項智能與教學

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/multiple-intelligences.md`
- 摘要：提供不同展現能力的途徑，但不把學生固定成某一型。
- 更新日期：2026-11-16

## 核心概念

Gardner 以多種相對不同的能力領域理解智能，講義以八項主要智能和教學應用為核心，另提存在智慧等延伸討論。

## 重點整理

- 八項常見智能：語文、邏輯數學、空間、肢體動覺、音樂、人際、內省、自然觀察。
- **人際**關注理解他人；**內省**關注理解自身。
- 同一任務可能同時運用多種智能。
- 活動可用文字、操作、圖像、音樂與合作等途徑表現理解。
- 課程不只配合優勢，也提供伸展與發展其他能力的機會。
- 存在智慧在講義中屬延伸討論，不混寫成與八項完全相同的確立地位。

## 教學實例（AI 自編）

地形單元讓學生畫示意圖、口頭解釋、製作模型，但各種成果都要呈現同一組地形判斷概念。

## 易混淆提醒

多元智能不是固定學習風格配對，也不是取消共同學習目標；避免只讓學生永遠做已擅長的事。

## 自我檢核（AI 自編）

能辨認自己的情緒、優勢與限制，較對應？

- A. 只有語文智能
- B. 內省智能
- C. 人際智能
- D. 自然觀察智能

**答案：B。** 內省智能聚焦對自己的理解。
