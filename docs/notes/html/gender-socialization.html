核心概念

講義以精神分析、社會學習、認知發展和性別基模等取向說明性別角色如何形成。整理重點是文化與認知歷程，不把性別當成固定能力指標。

重點整理

  • 社會學習取向：示範、模仿和社會回饋影響角色行為。
  • 認知發展取向：重視兒童如何認定與理解性別分類。
  • Bem 的性別基模：文化訊息與個體認知組織共同影響注意、分類和理解。
  • 性別刻板印象：把部分觀察概括成某類人理所當然的特性。
  • 教學提供多元角色、活動選擇和公平參與機會。

教學實例（AI 自編）

分配科學操作與紀錄工作時讓所有學生輪流擔任，不預設男生操作、女生美編。

易混淆提醒

講義中的歷史性別敘述不能直接當成現代學生的個別能力結論。穿著、興趣或行為也不能用來武斷推定個人認同。
