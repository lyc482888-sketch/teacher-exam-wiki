# 訊息處理：感官、工作與長期記憶

## 核心概念

訊息處理觀點把學習視為察覺、選擇、編碼、儲存與提取等歷程；既有知識也會回頭影響目前的理解。

## 重點整理

| 系統 | 功能線索 |
| --- | --- |
| 感官記憶 | 短暫保留感覺訊息 |
| 短期／工作記憶 | 有限的暫存與當下處理 |
| 長期記憶 | 保留知識、經驗及技能 |

- **注意**協助選擇要繼續處理的訊息。
- **編碼**把訊息轉成可處理的心理形式；**提取**把已有內容取出使用。
- **情節記憶**關於個人事件；**語意記憶**關於事實概念；**程序性知識**關於如何做。
- **組塊**把小單位組成較有意義的大單位。

## 教學實例（AI 自編）

學生先注意關鍵字，再把詞語依意義分類，最後不看課本解釋概念；分別對應選擇、組織與提取。

## 易混淆提醒

講義的 7±2 是特定經典研究脈絡，不能當成所有工作記憶任務的固定容量；短期記憶與工作記憶也不宜完全視為同義。
