# 生態系統論：微、中、外與鉅系統

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/ecological-systems.md`
- 摘要：同樣是環境影響，要看學生是否直接參與，以及環境間如何連結。
- 更新日期：2026-11-16

## 核心概念

Bronfenbrenner 的生態觀點把發展放進多層環境及其互動。講義聚焦四層系統，而不是只把問題歸在學生個人身上。

## 重點整理

| 系統 | 分析焦點 | 情境 |
| --- | --- | --- |
| 微系統 | 直接參與的環境 | 家庭、教室、同儕 |
| 中系統 | 微系統彼此的關係 | 親師合作 |
| 外系統 | 未直接參與卻間接影響 | 家長工作環境 |
| 鉅系統 | 文化、價值與制度脈絡 | 社會價值、制度期待 |

- 分類要從特定學生的位置判斷。
- 個人會影響環境，不只是單向被影響。

## 教學實例（AI 自編）

家長工作輪班改變接送與陪讀安排，影響學生學習；工作場域對學生而言是間接作用的外系統。

## 易混淆提醒

學校和家庭本身都是微系統；兩者之間的聯繫才是中系統。不能只看「規模大小」分類。

## 自我檢核（AI 自編）

家長與教師的聯繫和合作，屬於？

- A. 只屬鉅系統
- B. 感官記憶
- C. 中系統
- D. 只屬微系統

**答案：C。** 兩個直接環境之間的連結，是中系統。
