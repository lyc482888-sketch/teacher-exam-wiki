# 防衛機轉：合理化、投射與昇華

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/defense-mechanisms.md`
- 摘要：從心理作用的方向，分辨看似相近的防衛機轉。
- 更新日期：2026-11-16

## 核心概念

精神分析中的防衛機轉用來解釋個體如何減輕衝突與焦慮。辨題應看敘述中的功能，而不是只看行為表面。

## 重點整理

| 概念 | 辨認方式 |
| --- | --- |
| 合理化 | 以可接受的理由解釋挫折或行為 |
| 投射 | 將自身不易接納的想法歸到他人身上 |
| 否認 | 排拒令人不安的現實 |
| 退化 | 壓力下出現較早期的應對方式 |
| 補償 | 在其他領域追求平衡或成就 |
| 昇華 | 將動力轉為社會可接受的表現 |
| 反向形成 | 表現出與內在衝動相反的態度 |

## 教學實例（AI 自編）

虛構情境：學生比賽落選後說「那個比賽本來就沒意思」，可用來討論合理化；若改以持續創作表達情緒，分析焦點就不同。

## 易混淆提醒

不能僅憑一句話就判定真實學生的潛意識。此表供理論辨識，不把防衛機轉當作責備學生的標籤。

## 自我檢核（AI 自編）

將自身難以接受的想法說成是別人的想法，最接近？

- A. 前導組織
- B. 消弱
- C. 投射
- D. 昇華

**答案：C。** 投射的方向是把自身不易接納的內容歸於他人。
