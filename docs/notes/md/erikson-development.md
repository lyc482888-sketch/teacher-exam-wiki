# 艾里克森：心理社會發展八階段

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/erikson-development.md`
- 摘要：掌握每階段的發展任務，尤其國小階段的勤奮與自卑。
- 更新日期：2026-11-16

## 核心概念

艾里克森（Erik Erikson）以終身心理社會發展解釋個體與社會要求的互動。危機是發展任務中的張力，不表示人人都會出現臨床危機。

## 重點整理

| 階段 | 主要發展張力 |
| --- | --- |
| 嬰兒期 | 信任／不信任 |
| 幼兒期 | 自主／羞愧懷疑 |
| 學前期 | 主動／罪惡感 |
| 學齡期 | 勤奮／自卑 |
| 青少年期 | 自我認同／角色混淆 |
| 成年早期 | 親密／孤立 |
| 成年中期 | 生產繁衍／停滯 |
| 老年期 | 統整／絕望 |

- 國小教學重視可達成的挑戰、具體回饋與能力感。
- 發展不限童年，後續經驗仍重要。

## 教學實例（AI 自編）

教師把大任務拆成可完成的階段，讓學生看見進步，並避免以公開排名否定個人價值。

## 易混淆提醒

階段和年齡是理論概括，不是逐年必然達標的清單。某次失敗不能直接推論學生已固定形成自卑人格。

## 自我檢核（AI 自編）

國小階段最常對應的心理社會發展任務是？

- A. 統整與絕望
- B. 勤奮與自卑
- C. 親密與孤立
- D. 生產與停滯

**答案：B。** 學齡期重點是學習、工作能力和成就感的形成。
