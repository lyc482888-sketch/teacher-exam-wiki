# 教育與研究常見效應：如何分辨線索？

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/educational-effects.md`
- 摘要：整理期待、被觀察、整體印象和測驗太簡單等不同線索。
- 更新日期：2026-11-16

## 核心概念

講義列出多種心理效應、研究現象與管理比喻。本篇優先整理可清楚辨認的教育情境線索，不把所有「法則」都視為普遍因果定律。

## 重點整理

| 名稱 | 辨認線索 |
| --- | --- |
| 期待／比馬龍效應 | 他人期待經互動與機會影響表現 |
| 霍桑效應 | 察覺自己受觀察而改變表現 |
| 強亨利效應 | 控制組因競爭意識而格外努力 |
| 月暈效應 | 一項突出印象擴及其他判斷 |
| 天花板效應 | 任務太簡單，使高表現擠在上端 |
| 大魚小池效應 | 相同能力者因比較環境不同而有不同自我概念 |

- 巴雷托、木桶等比喻可作思考提示，不能直接當成精確教育定律。

## 教學實例（AI 自編）

學生作文內容普通，教師因他平常成績優秀而給出過高的整體評價，可用月暈效應分析評分偏誤。

## 易混淆提醒

效應不是看見一次就能證實的因果關係。控制組加倍努力與所有人知道被觀察，是不同的題目線索。

## 自我檢核（AI 自編）

試卷太簡單，多數學生接近滿分，難區分高能力學生，主要是？

- A. 語意記憶
- B. 天花板效應
- C. 角色混淆
- D. 負增強

**答案：B。** 測驗上端擁擠、區辨不足是天花板效應。
