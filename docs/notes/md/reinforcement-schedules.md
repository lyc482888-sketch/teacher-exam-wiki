# 增強時制與行為建立

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/reinforcement-schedules.md`
- 摘要：比例看反應次數，時距看時間；再分固定與變動。
- 更新日期：2026-11-16

## 核心概念

操作制約除了分增強與懲罰，也要看增強在什麼時機提供，以及新行為如何被逐步建立。

## 重點整理

| 時制 | 判斷依據 |
| --- | --- |
| 固定比例 FR | 固定次數反應後增強 |
| 變動比例 VR | 所需次數變動 |
| 固定時距 FI | 固定時間間隔後的適當反應可獲增強 |
| 變動時距 VI | 可獲增強的時間間隔變動 |

- **連續增強**：每次目標反應都增強，常用於建立行為。
- **塑造**：逐步增強更接近目標的反應；與把不同反應串起來的連鎖概念分開。
- **代幣**需有明確目標與兌換規則；不只是在教室貼點數。
- 改變不適當行為時，也要教可取代的適當行為。

## 教學實例（AI 自編）

每完成四次正確分類給一次回饋，屬固定比例的例子；接著逐步提高獨立完成的要求。

## 易混淆提醒

學校月考或發薪水的日常比喻不一定具備完整增強關係，要看題幹是否有反應與後果。理論分類不直接等於適當的管教措施。

## 自我檢核（AI 自編）

每完成固定數量的目標反應就給增強，屬於？

- A. 固定比例
- B. 變動比例
- C. 固定時距
- D. 變動時距

**答案：A。** 固定比例以固定反應次數為條件。
