# 古典制約：刺激之間的連結

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/classical-conditioning.md`
- 摘要：原本中性的刺激，經配對後也能引起制約反應。
- 更新日期：2026-11-16

## 核心概念

巴夫洛夫（Ivan Pavlov）的古典制約說明刺激配對的學習：原本不會引起某種反應的中性刺激，與能引起反應的刺激反覆配對後，可能單獨引起制約反應。

## 重點整理

| 名稱 | 功能 | 經典例子 |
| --- | --- | --- |
| 中性刺激 NS | 配對前不引起目標反應 | 配對前的鈴聲 |
| 非制約刺激 UCS | 不需此次學習即可引起反應 | 食物 |
| 非制約反應 UCR | 對非制約刺激的反應 | 食物引起唾液分泌 |
| 制約刺激 CS | 經配對後能引起制約反應 | 配對後的鈴聲 |
| 制約反應 CR | 對制約刺激的習得反應 | 聽鈴聲出現唾液反應 |

- 判題先找「什麼刺激與什麼刺激建立連結」。
- 同一個鈴聲，在配對前後的功能不同。

## 教學實例（AI 自編）

某提示音多次伴隨令學生緊張的情境，之後學生單聽提示音就感到緊張，可用古典制約觀點分析。這只是理論情境，實務上仍需了解其他影響因素。

## 易混淆提醒

不要只看到獎勵或行為變化就判為古典制約。古典制約偏重刺激配對；操作制約則看行為之後的結果如何影響往後行為。原講義個別表述有所簡化，這裡以此基本區分為主。

## 自我檢核（AI 自編）

鈴聲原本不引起唾液反應，配對食物後能引起反應；配對後的鈴聲稱為？

- A. 非制約刺激
- B. 非制約反應
- C. 制約刺激
- D. 懲罰

**答案：C。** 配對後具有引起制約反應功能的鈴聲，是制約刺激。
