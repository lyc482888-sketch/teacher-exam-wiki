# 皮亞傑的認知發展論

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/piaget-cognitive-development.md`
- 摘要：同化把新經驗放進舊基模，調適則改變基模。
- 更新日期：2026-11-16

## 核心概念

皮亞傑（Jean Piaget）關注兒童如何主動建構對世界的理解。發展不是只增加知識量，也包含思考方式的改變。面對新經驗，個體透過同化與調適尋求平衡。

## 重點整理

- **基模**：用來理解與處理經驗的認知結構。
- **同化**：用既有基模解釋新經驗。
- **調適**：修改既有基模，以容納不能直接解釋的新經驗。
- **平衡化**：面對失衡而調整理解的歷程。

| 理論階段 | 約略年齡 | 複習線索 |
| --- | --- | --- |
| 感覺動作期 | 0–2 歲 | 感覺動作、物體恆存 |
| 前運思期 | 2–7 歲 | 符號使用、集中化、自我中心 |
| 具體運思期 | 7–11 歲 | 具體情境的邏輯、可逆性、守恆 |
| 形式運思期 | 11 歲以上 | 抽象思考、假設演繹 |


## 教學實例（AI 自編）

學生原本認為「所有會飛的動物都是鳥」。看到蝙蝠時先叫牠鳥，是以舊基模同化；在比較動物特徵後，修改分類依據，則呈現調適。這是協助理解概念的例子，不代表真實學生發展診斷。

## 易混淆提醒

同化與調適不能只用「有沒有學到新知識」區分，要看原有基模是否改變。表中年齡是理論中的約略範圍，不能據此認定某年級學生一定只能或一定已能做某件事。原講義對形式運思後思維不再提升的說法過於絕對，本篇不採作結論。

## 自我檢核（AI 自編）

學生發現蝙蝠不是鳥，於是修改原先「會飛就是鳥」的分類依據，最符合哪個概念？

- A. 同化
- B. 調適
- C. 消弱
- D. 替代增強

**答案：B。** 修改原有基模以理解新經驗屬於調適；若只是套用舊分類，才是同化。
