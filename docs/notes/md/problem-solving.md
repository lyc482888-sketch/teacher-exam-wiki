# 問題解決：定程法、捷思法與固著

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/problem-solving.md`
- 摘要：先看問題如何被表徵，再選策略；熟悉的方法也可能成為限制。
- 更新日期：2026-11-16

## 核心概念

問題解決包含理解目標、已知條件、限制及可能策略。講義比較有結構問題、無結構問題，以及定程法與捷思法。

## 重點整理

- **定程法**：在適用條件下依明確步驟進行，可系統求解。
- **捷思法**：用經驗與線索縮小搜尋範圍，但不保證成功。
- **功能固著**：只想到物品慣常用途。
- **心向／定勢**：過度沿用先前有效的方法。
- **歸納**由事例歸結規律；**演繹**由原則或假設推到特定結論。
- 表徵錯誤可能讓後續計算再精確也解不對問題。

## 教學實例（AI 自編）

遇到新的排列題，學生先畫圖列出限制，再決定要逐項列舉，或運用已知規律縮小範圍。

## 易混淆提醒

捷思不是隨便猜，定程法也有適用前提；遇到生活開放問題不能假設都有單一標準解。

## 自我檢核（AI 自編）

因為只想到盒子的裝物用途，沒想到可把它用作支架，較符合？

- A. 功能固著
- B. 認同達成
- C. 替代增強
- D. 語文流暢

**答案：A。** 只使用物品慣常用途，是功能固著的典型線索。
