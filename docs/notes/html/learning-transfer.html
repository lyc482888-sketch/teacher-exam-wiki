核心概念

學習遷移是先前學習對後續學習的影響。講義以形式訓練、同元素、共同原則及完形關係等觀點解釋遷移。

重點整理

  • 正向遷移：舊學習有助於新學習；負向遷移：舊學習造成干擾。
  • 同元素論（Thorndike）：兩個情境共有的元素是遷移關鍵。
  • 共同原則（Judd）：理解可運用的原理原則，比只練同樣動作更重要。
  • 關係／轉換論：注意兩個情境的整體組織關係。
  • 水平遷移偏向擴大應用；垂直遷移偏向先備能力支援較高層學習。
  • 低徑常經熟練自動發生；高徑需抽象概括並刻意連結。

教學實例（AI 自編）

學生理解比例關係後，把相同比例概念運用到地圖比例尺；教師要請學生說明兩個問題共同的原理。

易混淆提醒

「題目看起來像」不代表深層原理相同。順攝與倒攝干擾則要看被影響的是新學習還是舊記憶。
