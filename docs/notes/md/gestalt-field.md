# 完形、頓悟與場地論

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/gestalt-field.md`

- 更新日期：2026-11-16

## 核心概念

完形心理學強調組織後的整體關係。講義接著介紹頓悟、Lewin 的場地論，以及 Witkin 的認知類型，名稱相近但問題焦點不同。

## 重點整理

- **完形組織**：接近、相似、封閉、連續等關係影響知覺組織。
- **頓悟**：重新理解情境關係後，找到解決方式。
- **Lewin**：行為與個人、環境的交互關係有關，可用 B=f(P,E) 表示。
- **Witkin**：場地獨立／依賴關注認知處理與背景線索的影響。
- 感覺是感官接收刺激，知覺涉及組織與解釋。
- 似動等現象提醒我們，知覺經驗不只是物理刺激的直接複本。
