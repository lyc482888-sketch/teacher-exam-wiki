# 編序教學、精熟學習與凱勒計畫

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/mastery-programmed-learning.md`
- 摘要：共同重視進度與回饋，但教學組織與精熟安排不同。
- 更新日期：2026-11-16

## 核心概念

講義把操作條件作用的教學應用整理為編序、精熟與個人化系統教學。比較時要看教材步驟、時間、評量和校正如何安排。

## 重點整理

| 方法 | 核心安排 |
| --- | --- |
| 編序教學 | 小步驟、主動反應、立即回饋、自訂步調 |
| 精熟學習 | 明確目標、形成性評量、校正與補救，再確認精熟 |
| 凱勒計畫 PSI | 單元精熟、自訂步調、書面教材及助理／同儕協助 |

- **Carroll** 提供學習時間觀點，**Bloom** 發展精熟學習模式。
- 校正不只是再做一次同一份測驗，應處理具體學習困難。
- 共同標準與個別所需時間，是比較的重要線索。

## 教學實例（AI 自編）

分數單元先做形成性小測；對等分概念尚不清楚者安排操作活動，再用新題確認理解。

## 易混淆提醒

精熟不是每個人同時完成，也不是無限重考分數。自訂步調仍需要清楚目標、支持與回饋。

## 自我檢核（AI 自編）

形成性評量後提供校正教學，再確認是否達標，最符合？

- A. 只有總結性排名
- B. 完全取消目標
- C. 只有被動重看教材
- D. 精熟學習

**答案：D。** 精熟學習強調以評量資訊調整教學並確認達標。
