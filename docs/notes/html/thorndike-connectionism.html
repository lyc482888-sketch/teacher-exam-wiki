桑代克：試誤學習與聯結律

核心概念

桑代克（Edward Thorndike）的聯結主義以試誤學習說明反應逐漸被保留。講義整理準備、練習與效果等學習律。

重點整理

  • 試誤：在多次嘗試中保留較有效的反應。
  • 準備律：學習者的準備狀態影響行動是否順利。
  • 練習律：練習與聯結的形成、維持有關。
  • 效果律：反應後的滿意結果有助於聯結保留。
  • 與操作制約相比，可看出對「後果影響行為」的共同關注。
  • 與遷移論相比，同元素論關注不同任務的共同成分。

教學實例（AI 自編）

學生嘗試不同拼圖位置，成功配對後更常採取相同有效策略；教師再引導他說出成功的特徵。

易混淆提醒

不能把大量重複直接當成有效學習，還要看練習品質、回饋與理解。歷史學習律也不等於對所有任務都無例外。
