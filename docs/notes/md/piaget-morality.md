# 皮亞傑的道德觀：他律與自律

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/piaget-morality.md`
- 摘要：比較規則是否可協商，以及判斷重結果還是重意圖。
- 更新日期：2026-11-16

## 核心概念

皮亞傑由兒童理解遊戲規則的方式討論道德發展。重點在兒童如何看待權威、規則及行為責任。

## 重點整理

| 他律取向 | 自律取向 |
| --- | --- |
| 規則由權威決定，難以改變 | 規則可由相互尊重與協議形成 |
| 較看重外在後果 | 更能考慮動機、意圖與情境 |
| 服從與單向限制 | 合作、互惠與平等 |

- 教學可讓學生參與規則討論、理解規則目的。
- 道德發展不只記住成人說的規定。

## 教學實例（AI 自編）

討論不小心打破三個杯子和故意打破一個杯子的故事，請學生說明數量、意圖與責任之間的關係。

## 易混淆提醒

不是「規則想改就改」，也不代表只要考慮意圖就忽略後果。年齡僅是理論中的概括線索。

## 自我檢核（AI 自編）

認為規則可以由參與者共同討論修改，較接近？

- A. 他律道德
- B. 刺激類化
- C. 自我設限
- D. 自律道德

**答案：D。** 協議、互惠與共同立規是自律道德的重要線索。
