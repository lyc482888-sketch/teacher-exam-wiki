從行為、認知結構與個人意義三種角度，辨認教學重點。

核心概念

教育心理學用心理學概念理解教育情境。講義先整理發展取向，再比較行為主義、認知論與人本論；同一個課堂行為，可以有不同分析角度。

重點整理

取向複習焦點教師可觀察什麼
行為主義刺激、反應、行為後果某行為在何種條件下增減
認知論理解、認知結構、記憶與策略學生如何解釋與組織知識
人本論主觀經驗、需求、自主與成長學習對學生有何個人意義
  • 教育心理研究要回到實際的學習情境。
  • 選擇教學方式時先確認目標，再看理論能解釋哪一部分。

教學實例（AI 自編）

學生不願作答時，可以分析作答後果、是否理解題目，以及是否缺少安全感或投入意義，而不是只用一種原因解釋。

易混淆提醒

不要把「行為主義＝學生永遠被動」「認知論＝不能講授」背成絕對命題。各理論的焦點和教法使用條件要分開。
