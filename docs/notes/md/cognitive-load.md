# 認知負荷、寫作歷程與專家新手

> 依 Wiki 整理的教甄複習筆記；不是新增資料來源。

- 整理依據：`wiki/concepts/cognitive-load.md`
- 摘要：資訊多不等於學得多；先備知識與組織方式影響當下負擔。
- 更新日期：2026-11-16

## 核心概念

工作記憶資源有限，學習者已有的基模與熟練程度會影響理解負荷。講義也以寫作與專家新手比較說明組織、策略及監控的重要性。

## 重點整理

- 新手常被表面特徵吸引，專家較能注意深層結構。
- 基模把相關訊息組織起來，較熟練的處理可減輕當下負擔。
- 教材可分段呈現，讓必要說明與對應圖示接近。
- 精緻化、概念圖與提問能協助連結先備知識。
- 寫作包括計畫、轉譯成文與回顧修訂；實際過程會往返。
- 提供範例與逐步撤除提示，可避免新手同時承擔太多工作。

## 教學實例（AI 自編）

教學生寫遊記時，先用共同範例辨認段落功能，再逐步安排列綱、成文和修改，而非一次要求完成全部。

## 易混淆提醒

降低負荷不是把所有挑戰取消；要移除的是不必要干擾，同時保留概念學習所需的思考。

新手一次要讀複雜圖表、聽長講解又抄筆記，主要需要考慮？
